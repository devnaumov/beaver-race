# Beaver Race

Интерактивная 3D-гонка бобров на Vite, React, Effect 4, Effect Atom, XState и Three.js.

Рождественская тема: заснеженная трасса, украшенные ели, подарки и 31 объёмный предмет экипировки. Снегопад отключается при `prefers-reduced-motion`.

## Редактор персонажа

В лобби нажмите **Edit** рядом с участником, в том числе только что добавленным. В мастерской доступны:

- Семь независимых слотов: головной убор, лицо, шея, костюм, основная лапа, вторая лапа и спина. Можно смешивать рождественские вещи и приключенческое снаряжение, снять отдельный предмет или всё сразу.
- Шапки Санты и эльфа, рога, шарф, бубенчики, костюмы, леденец, фонарь, подарки, какао, пряник, мешок, венок и ёлочка. Для зимнего рыцаря есть мечи, топор, щиты, броня, корона и плащ.
- Цвет меха и акцента, четыре телосложения, размер головы, хвоста, ушей и зубов, цвет мордочки/живота и значок команды.
- Живое 3D-превью: перетаскивание и кнопки вращения, приближение, **Test run**. При `prefers-reduced-motion` анимация превью не проигрывается.

**Save character** сохраняет изменения, **Cancel**, крестик и Escape отменяют примерку. Внешность и экипировка хранятся локально в браузере, в `beaver-race:characters:v1`; старый список имён автоматически подхватывается. Во время гонки редактирование недоступно. Экипировка только косметическая, на исход гонки не влияет.

Бобр создан процедурно: настоящий скелет Three.js, взвешенный `SkinnedMesh` корпуса, суставы лап, подвижные голова и хвост. Предметы привязаны к костям/сокетам, включая предметы в лапах. Бег перенесён из свободной анимации Quaternius (CC0), воспроизводится через `AnimationMixer` и плавно смешивается с покоем. Источник и способ повторного импорта описаны в `THIRD_PARTY_ASSETS.md`.

Гонка длится 20 секунд (не считая отсчёта и финишного пробега). Длительность задаётся константой `DEFAULT_RACE_DURATION` в `src/race/RaceCourse.ts`, в миллисекундах. Камера сопровождает участников, окружение переиспользуется по ходу движения, а финиш появляется только на заключительном участке. Увеличение длительности удлиняет маршрут, не растягивая промежутки между бобрами и не увеличивая количество объектов сцены.

После нажатия Start сначала показывается семисекундная сцена знакомства на зимней поляне: участники в выбранных костюмах сидят на брёвнах, машут, держат подарки и греются у костра. Камера облетает компанию, затем начинается отсчёт и сама гонка. Длительность вступления задаётся `PREVIEW_DURATION` в том же файле. При `prefers-reduced-motion` вступление показывается без облёта и фоновых анимаций.

## Запуск

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
npm test
npm run preview
```

## Архитектура

- `src/gameMachine.ts` содержит основное состояние игры, countdown actor и simulation actor XState.
- `src/store.ts` запускает machine actor и синхронизирует snapshot с Effect Atom.
- `src/race/` содержит классы фаз темпа, генератор плана и непрерывные траектории гонки.
- `src/race/RaceCourse.ts` задаёт длительность, длину маршрута и локальные координаты участников относительно движущегося окружения.
- `src/three/beaver/` содержит базовую модель, части тела, аксессуары, аниматор и представление участника.
- `src/equipment.ts` описывает каталог и слоты; `EquipmentModels.ts` создаёт геометрию предметов.
- `src/CharacterEditor.tsx` и `src/three/beaver/CharacterPreview.ts` реализуют мастерскую; `src/character.ts` проверяет и сохраняет настройки внешности.
- `src/christmas.ts` содержит названия костюмов, а `src/three/core/ChristmasMeshes.ts` содержит общие модели подарков, праздничных шапок и звёзд.
- `src/three/environment/` содержит классы неба, облаков, реки, берегов, леса, дорожки, флагов, фонового поединка и разрываемой финишной ленты.
- `src/three/BeaverRaceScene.ts` компонует Three.js runtime, связывает его с actor и управляет постановочными планами камеры по ходу гонки.
- Состояние гонки хранится в XState и читается через Effect Atom. Несохранённая примерка и камера мастерской локальны редактору и не меняют гонку до сохранения.

Источники SVG-логотипов перечислены в `THIRD_PARTY_ASSETS.md`.
