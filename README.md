# Beaver Race

Интерактивная 3D-гонка бобров на Vite, React, Effect 4, Effect Atom, XState и Three.js.

Рождественская тема: заснеженная трасса, украшенные ели, подарки и шесть праздничных костюмов. Снегопад отключается при `prefers-reduced-motion`.

Гонка длится 20 секунд (не считая отсчёта и финишного пробега). Длительность задаётся константой `DEFAULT_RACE_DURATION` в `src/race/RaceCourse.ts`, в миллисекундах. Камера сопровождает участников, окружение переиспользуется по ходу движения, а финиш появляется только на заключительном участке. Увеличение длительности удлиняет маршрут, не растягивая промежутки между бобрами и не увеличивая количество объектов сцены.

После нажатия Start сначала показывается семисекундная сцена знакомства на зимней поляне: участники в выбранных костюмах сидят на брёвнах, машут, держат подарки и греются у костра. Камера облетает компанию, затем начинается отсчёт и сама гонка. Длительность вступления задаётся `PREVIEW_DURATION` в том же файле. При `prefers-reduced-motion` вступление показывается без облёта и фоновых анимаций.

## Запуск

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
npm test
npm run preview
```

## Архитектура

- `src/gameMachine.ts` содержит основное состояние игры, countdown actor и simulation actor XState.
- `src/store.ts` запускает machine actor и синхронизирует snapshot с Effect Atom.
- `src/race/` содержит классы фаз темпа, генератор плана и непрерывные траектории гонки.
- `src/race/RaceCourse.ts` задаёт длительность, длину маршрута и локальные координаты участников относительно движущегося окружения.
- `src/three/beaver/` содержит базовую модель, части тела, аксессуары, аниматор и представление участника.
- `src/christmas.ts` содержит названия костюмов, а `src/three/core/ChristmasMeshes.ts` содержит общие модели подарков, праздничных шапок и звёзд.
- `src/three/environment/` содержит классы неба, облаков, реки, берегов, леса, дорожки, флагов, фонового поединка и разрываемой финишной ленты.
- `src/three/BeaverRaceScene.ts` компонует Three.js runtime, связывает его с actor и управляет постановочными планами камеры по ходу гонки.
- React-компоненты читают Effect Atom; локальные `useState` и `useEffect` не используются.

Источники SVG-логотипов перечислены в `THIRD_PARTY_ASSETS.md`.
